# NDCA Steganography

A personal implementation project based on **Neighboring block Differences-based Cost Assignment (NDCA)** for robust video steganography. The goal is to explore embedding hidden data in video and recovering it after lossy compression, such as transcoding on social networks.

## Reference

Jie Gan, Hong Zhang, Xinrui Xie, and Yun Cao (2025). [NDCA: a neighboring block differences-based cost assignment method for robust video steganography on social networks](https://doi.org/10.1186/s13635-025-00214-6).
